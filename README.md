# Business AI Automation Suite

![Business AI Automation Suite](./assets/business-ai-automation-suite.png)

A portfolio collection of three Make.com automation projects designed for real business workflows across Sales, Customer Support, and Finance Operations.

## Projects

### 1. AI Lead Qualification Agent

An automated lead qualification workflow that evaluates incoming leads, enriches lead data, updates records, and supports faster sales follow-up.

**Business Area:** Sales Automation

### 2. AI Knowledge Support Agent

An AI-powered support automation that receives user questions, uses web search and internal knowledge sources, and returns relevant answers automatically.

**Business Area:** Customer Support Automation

### 3. AI Telegram Invoice Extractor

A Telegram-based automation that receives invoice files, extracts key invoice information, converts it into structured data, and stores the result automatically.

**Business Area:** Finance / Operations Automation
