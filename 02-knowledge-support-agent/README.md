# AI Knowledge Support Agent

![Knowledge Support Agent Workflow](../assets/knowledge-support-agent-workflow.png)

A Make.com AI support workflow that receives questions through Telegram, uses web search and a connected knowledge source, and returns relevant answers automatically.

## Business Problem

Support teams often spend time answering repeated or information-heavy questions. This can slow down response times and create inconsistent answers.

## Solution

This automation receives a user question through Telegram, sends the request to an AI agent, allows the agent to use web search and connected knowledge, and returns the generated answer automatically.

## Workflow

1. Receive a user question through Telegram
2. Pass the question to the AI agent
3. Search the web when additional information is needed
4. Retrieve relevant information from the connected knowledge source
5. Generate a response
6. Send the answer back through Telegram
